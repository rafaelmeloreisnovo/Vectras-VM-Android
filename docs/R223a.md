7. Fibonacci direta, inversa e tribonacci

Fibonacci-Rafael direta

F_R=(0,0,0,1,1,2,3,5,8,\dots)

Fibonacci inversa

A inversa não é apenas voltar números. É recuperar origem:

F_R^{-1}(n):
F_k \rightarrow F_{k-1},F_{k-2}

Mas com memória:

5 \rightarrow 3+2

3 \rightarrow 2+1_\mu

2 \rightarrow 1+1

1 \rightarrow 0+1

0 \rightarrow TOKEN\_VAZIO

Então:

\boxed{
F_R^{-1}=\text{genealogia, não simples subtração}
}

Tribonacci

A tribonacci entra quando o sistema precisa de três memórias:

T_n=T_{n-1}+T_{n-2}+T_{n-3}

No teu modelo, isso combina com:

0_1,0_2,0_3

A tripla origem vira motor:

1. dado um símbolo;


2. obter byte/código;


3. obter som/TTS;

5. obter forma geométrica;


6. obter base numérica;

10. reproduzir o mesmo resultado em outra execução.



Formalmente:

Proof(c)=

Proof_t(c)\neq Proof_{t+1}(c)

registrar:

\Delta Proof(c)

não apagar.
